ITCalider App
Aplicación académica funcional en local para gestionar usuarios, avisos, horarios, calificaciones y comunidad.

Descripción
ITCalider es un prototipo funcional de una plataforma académica diseñada para simular el flujo de un sistema escolar dentro del navegador. La versión actual incluye:

inicio de sesión
gestión de sesión
dashboard académico
avisos
horario
calificaciones
foro/comunidad
Tecnologías
HTML, CSS y JavaScript
Node.js
Express
SQLite
JWT para sesiones
Requisitos
Node.js 18+
npm
